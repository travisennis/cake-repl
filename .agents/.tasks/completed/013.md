# Fix session summary file path — missing 'share' component

**Based on audit finding CORRECT-01** — audit commit `fe9b393`

## Problem

`cmd/cake-repl/main.go:112` constructs the session file path as
`~/.local/cake/sessions/<uuid>`, but cake stores sessions at
`~/.local/share/cake/sessions/<uuid>` (confirmed via cake's GitHub README).
The path is missing the `share` component. Every time the TUI exits with an
active session, the printed `file:` path doesn't exist.

Current code:

```go
fmt.Fprintf(os.Stderr, "file: %s\n",
    filepath.Join(home, ".local", "cake", "sessions", sessionID))
```

## Relevant files

- `cmd/cake-repl/main.go:110-114` — session summary printing after TUI exit
- Cake's README — confirms `~/.local/share/cake/sessions/` as the session
  storage path (or `$CAKE_DATA_DIR/sessions/` when `CAKE_DATA_DIR` is set)

## Fix direction

1. Change the path from `filepath.Join(home, ".local", "cake", "sessions", sessionID)`
   to `filepath.Join(home, ".local", "share", "cake", "sessions", sessionID)`.

2. Optionally respect `$CAKE_DATA_DIR` if set, falling back to
   `~/.local/share/cake/sessions/`. Cake supports `CAKE_DATA_DIR` as an
   override for its data directory. If set, sessions live at
   `$CAKE_DATA_DIR/sessions/<uuid>`. This makes the path correct for users
   who customize their cake data directory.

3. Add a test for the path construction. Extract the path-building logic
   into a testable function (e.g., `sessionFilePath(home, sessionID string) string`)
   or test it as part of a broader `main.go` test effort.

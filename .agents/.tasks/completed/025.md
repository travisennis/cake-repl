# Include .jsonl extension in exit session file path

## Problem

After a session, cake-repl prints a resume hint whose `file:` path omits the
session file's `.jsonl` extension:

```text
Resume this session with:
cake-repl -resume cbc54120-b06d-4832-bfee-8ad80f58906d
file: ~/.local/share/cake/sessions/cbc54120-b06d-4832-bfee-8ad80f58906d
```

Cake stores the session as
`~/.local/share/cake/sessions/<session-id>.jsonl` (or
`$CAKE_DATA_DIR/sessions/<session-id>.jsonl`). The displayed path therefore
points to a nonexistent file. This is a follow-up regression to task 013,
which corrected the directory but retained the extensionless filename.

## Relevant files

- `cmd/cake-repl/main.go` - `sessionFilePath` and the exit session summary
- `cmd/cake-repl/main_test.go` - existing default, `CAKE_DATA_DIR`, and display-path tests

## Fix direction

Append `.jsonl` when `sessionFilePath` constructs the filename. Update the
existing path tests to require the complete filename for both the default data
directory and `CAKE_DATA_DIR`. Keep this display-only: cake-repl must not read,
parse, or otherwise inspect cake session files.

No README or help-text change is expected because this corrects an existing
path rather than changing a documented command or flag.

## Acceptance notes

- [x] The exit summary prints `~/.local/share/cake/sessions/<session-id>.jsonl` with the default data directory.
- [x] With `CAKE_DATA_DIR` set, the exit summary prints `$CAKE_DATA_DIR/sessions/<session-id>.jsonl`.
- [x] Focused tests cover the `.jsonl` suffix in both path variants (3 tests: default, `CAKE_DATA_DIR`, and empty-fallback).
- [x] cake-repl does not read, parse, or write cake session files — only the display path changed.
- [x] `just test` passes.
- [x] `just ci` passes before implementation handoff.

## Implementation notes

Fix applied in two files:

- **`cmd/cake-repl/main.go`**: `sessionFilePath` now appends `.jsonl` to `sessionID` in both the `CAKE_DATA_DIR` branch (`sessionID+".jsonl"`) and the default `~/.local/share/...` branch.
- **`cmd/cake-repl/main_test.go`**: Updated `TestSessionFilePathDefaultsToShare`, `TestSessionFilePathRespectsCAKEDATADIR`, and `TestSessionFilePathEmptyCAKEDATADIRFallsBack` to expect the `.jsonl` extension.

No other files changed. No cake session files are read, parsed, or written.

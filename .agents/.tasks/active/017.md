# Add tests for main.go flag validation

**Based on audit finding TESTS-03** — audit commit `fe9b393`

## Problem

`cmd/cake-repl/main.go:34-48` — flag validation for `--continue`/`--resume`
mutual exclusivity, UUID shape, positional arg rejection, and `--cwd`
directory check. No tests — `go test` reports `[no test files]` for the
`cmd/cake-repl` package.

Current validation code:

```go
if *showVersion {
    fmt.Fprintln(os.Stdout, version.Binary)
    return nil
}
if flag.NArg() > 0 {
    return fmt.Errorf("unexpected argument %q (prompts are entered inside the REPL)", flag.Arg(0))
}
if *continueFlag && *resume != "" {
    return fmt.Errorf("--continue and --resume are mutually exclusive")
}
if *resume != "" && !app.IsSessionID(*resume) {
    return fmt.Errorf("invalid --resume uuid: %s", *resume)
}
```

## Relevant files

- `cmd/cake-repl/main.go` — `run()` function, flag parsing, validation
- `internal/app/commands.go:21-24` — `IsSessionID` (shared UUID regex)
- `internal/app/commands_test.go` — existing tests for `ParseCommand` UUID
  validation (pattern to follow)

Out of scope: testing the full TUI startup, testing `tea.Program.Run()`.

## Fix direction

1. Extract the validation logic from `run()` into a testable function:

   ```go
   func validateFlags(showVersion bool, continueFlag bool, resume string, args []string) error {
       if showVersion {
           return nil
       }
       if len(args) > 0 {
           return fmt.Errorf("unexpected argument %q (prompts are entered inside the REPL)", args[0])
       }
       if continueFlag && resume != "" {
           return fmt.Errorf("--continue and --resume are mutually exclusive")
       }
       if resume != "" && !app.IsSessionID(resume) {
           return fmt.Errorf("invalid --resume uuid: %s", resume)
       }
       return nil
   }
   ```

2. Create `cmd/cake-repl/main_test.go` with table-driven tests:

   - `--continue` and `--resume` both set → error
   - `--resume` with valid UUID → no error
   - `--resume` with invalid UUID → error
   - Positional arg present → error
   - `--version` flag → no error (short-circuits other validation)
   - No flags, no args → no error
   - `--continue` alone → no error
   - `--resume` alone with valid UUID → no error

3. Also extract and test the `--cwd` directory check if practical (it
   requires filesystem access, so may need `t.TempDir()`).

# Tune assistant markdown styling to match the REPL theme

## Summary

Tune assistant markdown rendering so responses feel integrated with cake-repl's UI theme instead of using Glamour's stock dark style unchanged. Markdown support is already present and useful, but the built-in style may not align with the app's color, spacing, and hierarchy once the rest of the terminal chrome is improved. This task should produce readable assistant output that fits the REPL's visual language while preserving no-color behavior.

Written against commit `a9b0ced`.

Depends on task `042` so markdown styling can align with shared theme roles and palette decisions.

## Evidence

- `internal/ui/markdown.go:23` — `RenderMarkdown` creates a Glamour renderer with `glamour.WithStandardStyle("dark")`, so assistant markdown styling is controlled by a generic preset rather than the app theme.
- `internal/ui/timeline.go:70` — assistant messages route directly to `RenderMarkdown`, while other timeline item kinds use `ui.Theme` styles.
- `internal/ui/theme.go:31` — `Assistant` is intentionally plain, which means the theme currently has no real influence over markdown assistant output.
- `internal/ui/markdown.go:42` — ASCII/no-color fallback behavior is already handled and must be preserved if the style is customized.

## Fix Direction

Evaluate whether to keep the Glamour preset with small surrounding adjustments or provide a custom Glamour style that matches the expanded `ui.Theme`. Keep markdown rendering encapsulated in `internal/ui/markdown.go` and avoid changing assistant message event handling. Preserve word wrapping, plain-text fallback, and no-color output under `termenv.Ascii`. If a custom style would require large duplicated style JSON or a new dependency, stop and propose a smaller scoped alternative.

## Acceptance Notes

- [ ] Assistant markdown output visually aligns with the REPL theme for headings, lists, code blocks, blockquotes, links, and emphasis where supported by Glamour.
- [ ] Word wrapping still respects the supplied width, including narrow widths.

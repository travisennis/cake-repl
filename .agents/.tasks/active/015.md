# Add tests for loadHistory

**Based on audit finding TESTS-01** — audit commit `fe9b393`

## Problem

`internal/app/model.go:74-93` — `loadHistory` opens a file, scans lines,
trims to `maxHistoryEntries`, and rewrites the file if over the cap. Zero
test coverage. The trimming logic (`entries[len(entries)-maxHistoryEntries:]`)
and the file rewrite (`os.WriteFile` with `0o600`) are both untested.

Current code:

```go
func (m *Model) loadHistory(path string) {
    f, err := os.Open(path)
    if err != nil {
        return
    }
    defer f.Close()

    var entries []string
    sc := bufio.NewScanner(f)
    for sc.Scan() {
        if line := sc.Text(); line != "" {
            entries = append(entries, line)
        }
    }

    if len(entries) > maxHistoryEntries {
        entries = entries[len(entries)-maxHistoryEntries:]
        data := strings.Join(entries, "\n") + "\n"
        _ = os.WriteFile(path, []byte(data), 0o600)
    }

    m.history.entries = entries
    m.history.idx = len(entries)
}
```

## Fix direction

Create test cases in a new `internal/app/history_io_test.go` (or add to
`model_test.go`):

1. **Normal load** — write a file with 3 entries, call `New(Config{HistoryFile: path})`,
   verify `m.history.entries` has 3 entries in order.
2. **Over-cap trim + rewrite** — write a file with `maxHistoryEntries + 5`
   entries, call `New(...)`, verify only the last `maxHistoryEntries` are
   loaded and the file was rewritten with exactly those entries.
3. **Empty file** — write an empty file, verify `m.history.entries` is nil/empty.
4. **Nonexistent file** — pass a path that doesn't exist, verify no panic,
   no error, entries empty.
5. **Blank lines skipped** — file with blank lines between entries, verify
   they're not included.

Use `t.TempDir()` for temp files. Follow the pattern from `history_test.go`
(table-driven where applicable, `t.Helper()` for helpers).

# Add test file for internal/version package

**Based on audit finding TESTS-01** — audit commit `05f0916`

## Problem

The `internal/version` package has zero test coverage. It exports one variable (`Binary`, overridden by release ldflags), and there is no assertion that the default value is `"dev"` or that the ldflags override path works.

Current state (`internal/version/version.go`):

```go
// Package version holds the cake-repl binary version string.
package version

// Binary is the cake-repl binary version, overridden by release ldflags.
var Binary = "dev"
```

## Relevant files

- `internal/version/version.go` — the only file in the package
- `internal/version/version_test.go` — does not exist yet; create it

Out of scope: any form of ldflags injection test at the build level (covered by GoReleaser and `just release-check`).

## Fix direction

1. Create `internal/version/version_test.go` with:
   - `TestBinaryDefault` — assert `Binary == "dev"`
   - `TestBinaryOverride` — set `Binary = "1.2.3"`, assert; then restore (or use sub-test with defer, or use a fresh copy via a helper — simplest: just test the default, since the `var` is trivially settable).

   Follow the project's test conventions from `CONTRIBUTING.md`: name tests after behavior (`TestBinaryDefault`, `TestBinaryOverride`), use `testing.T`.

2. Run `go test ./internal/version/` to confirm the tests pass.

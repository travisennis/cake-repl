# Tool output wrapping for names and arguments

## Problem

Tool output blocks show the tool name and its arguments in the header, but long tool names (especially Bash commands) get truncated instead of wrapping. This makes it difficult to see the full command that was executed, which is critical for Bash tools where the command is the most important piece of information.

Current rendering (in `internal/ui/toolblock.go`) applies width constraints that truncate rather than wrap the tool name and argument display.

## Proposed solution

Make the tool name and argument display wrap (word-wrap or line-wrap) within the available width so the full command is always visible. This may involve:

- Changing width-constrained rendering to allow wrapping in the tool header
- Adjusting any fixed-height assumptions in the tool block rendering
- Ensuring wrapped content respects indentation

Out of scope: changing tool output content truncation (that's task 010 / 005).

## Relevant files

- `internal/ui/toolblock.go` — `renderTool`, tool name/args rendering
- `internal/ui/timeline.go` — tool block dimensions
- `internal/app/update.go` — tool event handling

# Unify command list between completion.go and ParseCommand

**Based on audit finding TECH-01** — audit commit `fe9b393`

## Problem

`internal/app/completion.go` maintains a hardcoded `knownCommands` list with a
comment "Keep this in sync with ParseCommand." `internal/app/commands.go`
has its own switch in `ParseCommand` with the canonical command names. Two
sources of truth — adding a new slash command to one but not the other
silently breaks Tab completion or command parsing.

Current state:

- `completion.go:6-16` — `knownCommands` slice: `/help`, `/exit`, `/new`,
  `/continue`, `/resume`, `/session`, `/clear`, `/quit`, `/q`
- `commands.go:45-72` — `ParseCommand` switch: same commands, separately
  maintained

## Relevant files

- `internal/app/completion.go` — `knownCommands`, `completeSlash`
- `internal/app/commands.go` — `ParseCommand`, `CommandKind`, `Command`
- `internal/app/completion_test.go` — existing tests for `completeSlash`
- `internal/app/commands_test.go` — existing tests for `ParseCommand`

Out of scope: changing the set of commands, adding new commands, or changing
completion behavior.

## Fix direction

1. Define a single package-level table that both functions reference:

   ```go
   var commandTable = []struct {
       name string
       kind CommandKind
   }{
       {"/help", CmdHelp},
       {"/exit", CmdExit},
       {"/new", CmdNew},
       {"/continue", CmdContinue},
       {"/resume", CmdResume},
       {"/session", CmdSession},
       {"/clear", CmdClear},
       {"/quit", CmdExit},
       {"/q", CmdExit},
   }
   ```

2. Refactor `ParseCommand` to look up the command name in `commandTable`
   instead of a switch. The `/resume` special case (requires a UUID arg)
   stays as a post-lookup check.

3. Refactor `completeSlash` to iterate `commandTable` for matching names
   instead of `knownCommands`. Remove `knownCommands`.

4. Run existing tests to verify no behavior change:
   `go test github.com/travisennis/cake-repl/internal/app`

## Acceptance notes

- [ ] `just test` passes

## Maintenance note

When adding a new slash command, add one entry to `commandTable`. Both
parsing and completion pick it up automatically.

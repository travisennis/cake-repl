# Global tool output mode — Ctrl+O toggles all tool blocks

**Follow-up to task 010** (per-item expansion of the most recent tool block).

## Problem

Task 010 made `Ctrl+O` cycle the output mode of only the most recent tool
block, with per-item state. In practice the toggle is invisible: truncated and
full render identically whenever output is under the output limit, there is no
mode indicator, and the targeted block may be scrolled off-screen. The result
is a keybinding that appears to do nothing.

## Decisions (2026-07-18)

1. **Global mode**: `Ctrl+O` cycles a single session-wide `ToolOutputMode`
   that applies to **all** tool blocks — the entire existing timeline updates
   at once, and tool output arriving later renders in the current mode.
2. **Replaces per-item state entirely**: drop the `OutputMode` field from
   `ui.ToolBlock`; the mode lives on the app model and is passed into
   rendering. No per-item overrides.
3. **Cycle order unchanged**: truncated → full → hidden → truncated.
   Startup default is truncated.
4. **Viewport**: same policy as today — stay pinned if at the bottom,
   otherwise best-effort restore of the previous `YOffset`.
5. **Persistence**: session-only, in-memory. `/clear` wipes the timeline but
   keeps the current mode. No CLI flag for the startup default.
6. **Mode visibility is out of scope**: no indicator/badge yet. Toggling
   everything at once should make the state change obvious enough for now; an
   indicator can be a follow-up task.

This supersedes two task 010 constraints: "the truncated/full state should be
per-item, not global" and "must not re-render the full timeline on toggle".
A global toggle inherently re-renders every `KindTool` item; cached renders of
non-tool items should still be reused.

## Relevant files

- `internal/app/model.go` — global mode field; re-render all tool items on toggle
- `internal/app/update.go` — `toggleMostRecentToolOutput` becomes a global toggle
- `internal/ui/timeline.go` — remove `ToolBlock.OutputMode`; thread mode through `RenderItem`/`renderTool`
- `internal/app/commands.go` — `/help` text
- `README.md`, `docs/guardrails/cli-and-user-output.md` — key binding docs
- `docs/adr/003-tool-output-expansion-key-binding.md` — amend with the global-mode decision

## Acceptance

- [x] `Ctrl+O` cycles truncated → full → hidden for every tool block in the timeline at once
- [x] Tool output arriving after a toggle renders in the current mode
- [x] Only `KindTool` items are re-rendered on toggle; other cached renders are reused
- [x] Viewport stays pinned to bottom when it was at the bottom; otherwise the previous offset is restored
- [x] `/clear` does not reset the mode
- [x] `ui.ToolBlock` no longer carries per-item output mode state
- [x] `/help`, README, and the CLI guardrail describe the global behavior; ADR-003 amended
- [x] `just ci` passes

# Add key binding to copy the last assistant response (markdown) to the clipboard

## Summary

Ctrl+Y copies the raw markdown of the most recent assistant message to the system clipboard (pbcopy/xclip/clip via atotto/clipboard). Add key binding, model helper, feedback items, tests, and docs (README, HelpText, cli-and-user-output guardrail).

## Acceptance Notes

- [x] `Ctrl+Y` copies the raw markdown of the most recent `KindAssistant` timeline item (reaching back past trailing tool/completion items) to the system clipboard via `atotto/clipboard` (`pbcopy`/`xclip`/`xsel`/`clip`).
- [x] Timeline feedback: info notice with copied char count on success, warning when no assistant response exists, error when the clipboard helper fails.
- [x] Clipboard write is injectable (`Model.clipboard`), so tests are hermetic and never touch the real system clipboard.
- [x] Docs updated: `README.md` keybindings table + note, `HelpText`, `docs/guardrails/cli-and-user-output.md`, and the secrets bullet in `docs/guardrails/session-and-security.md` (explicit user-initiated exception).
- [x] `atotto/clipboard` promoted from indirect to direct dependency; `go mod tidy` stable.
- [x] `just ci` green (fmt-check, tidy-check, vet, test-race, lint, vuln, build, release-check).

## Documentation / ADR Notes

- User docs: `README.md` (keybindings table + clipboard-helper note).
- Guardrails: `docs/guardrails/cli-and-user-output.md` (key bindings list + output rendering behavior), `docs/guardrails/session-and-security.md` (secrets bullet carves out the explicit Ctrl+Y exception).
- ADR: not required. The documentation impact matrix row for key bindings requires only `README.md`, `HelpText`, and the `cli-and-user-output.md` guardrail — all updated. The automatic secrets contract, ADR 005's render-boundary defense, subprocess lifecycle, and persisted state are unchanged: the copy is explicit, one-shot, and human-initiated, never automatic. No new dependency beyond promoting `atotto/clipboard` (already in the module graph via bubbles/textarea) to direct.

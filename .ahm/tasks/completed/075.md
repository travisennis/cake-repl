# Show first and last lines of multi-line bash commands in tool headers

## Problem

Multi-line bash tool calls showed only the first line of the command in the
tool header (`$ cd /path…`), which often hid the actual payload behind setup
lines like `cd` or `export`.

## Solution

`summarizeBash` now renders multi-line commands as first and last non-empty
lines joined by ` … `, e.g. `$ cd /path … make test`. Single-line commands are
unchanged; the summary stays single-line so the wrap-not-truncate header
rendering is preserved. The 160-cell compact-JSON fallback for malformed args
is unchanged.

## Files

- `internal/ui/toolblock.go` — `summarizeCommand`/`nonEmptyLines` helpers
  (replaces `firstLineNoLimit`).
- `internal/ui/toolblock_test.go` — strengthened multiline case; added
  elision, blank-line, and repeated-endpoint tests.
- `docs/guardrails/cli-and-user-output.md` — documented the first/last-line
  rule.

# Add tab completion for slash commands

**Based on audit finding DX-02** — audit commit `05f0916`

## Problem

The REPL defines 7 slash commands (`/help`, `/exit`, `/quit`, `/q`, `/new`, `/continue`, `/resume`, `/session`, `/clear`), all of which must be typed from memory. There is no tab completion. The input is a Bubble Tea `textarea` with no custom key handling for Tab.

Additionally, `/resume <uuid>` requires typing a full UUID — the user may have recently used a session that could be suggested.

## Relevant files

- `internal/app/commands.go` — `CommandKind` enum, `ParseCommand`, `HelpText`, known command list
- `internal/app/keys.go` — `keyMap` struct, `defaultKeyMap`, needs a new `TabComplete` binding
- `internal/app/update.go` — `handleKey` switch, needs a new case for Tab
- `internal/app/model.go` — `session.SessionID`, `session.ResumeID` (available for UUID completion)
- `internal/app/session.go` — `sessionState` with session/resume IDs
- `internal/app/model_test.go` — test infrastructure (`newLaidOutModel`)
- `cmd/cake-repl/main.go` — if any flag changes needed
- `README.md` — keybindings table to update

Out of scope: file path completion, tool name completion, history search with tab, or fancy popup overlays. Keep it simple: inline text replacement at cursor position.

## Fix direction

### Step 1: Add Tab key binding

In `internal/app/keys.go`:

```go
type keyMap struct {
    // ... existing fields
    TabComplete key.Binding
}

func defaultKeyMap() keyMap {
    return keyMap{
        // ... existing bindings
        TabComplete: key.NewBinding(key.WithKeys("tab")),
    }
}
```

### Step 2: Implement completion logic

Add a new unexported function in `commands.go` (or a new file `internal/app/completion.go`):

```go
// completeSlash returns the completed text and whether it changed.
// If the input starts with "/", it matches against known commands.
// If the input is "/resume " followed by partial text, it matches
// against known session IDs.
func completeSlash(input string, knownSessions []string) (string, bool)
```

Logic:

- If input doesn't start with `/`, no complete.
- If input is exactly `/` or a partial command prefix (e.g., `/he`), complete to the longest matching command. If multiple matches (e.g., `/q` matches `/quit`, `/q`), cycle through or complete to the common prefix.
- If input starts with `/resume ` and has partial UUID text, match against `knownSessions` (from `session.SessionID` and `session.ResumeID` present in the model).

Cycle behavior: pressing Tab repeatedly cycles through completions. Return to the original prefix after the last completion.

### Step 3: Wire in handleKey

In `internal/app/update.go`, add before the fallthrough `m.input.Update(msg)`:

```go
case key.Matches(msg, m.keys.TabComplete):
    known := []string{}
    if m.session.SessionID != "" {
        known = append(known, m.session.SessionID)
    }
    if m.session.ResumeID != "" {
        known = append(known, m.session.ResumeID)
    }
    completed, ok := completeSlash(m.input.Value(), known)
    if ok {
        m.input.SetValue(completed)
        m.layout()
    }
    return m, nil
```

### Step 4: Add tests

In `internal/app/commands_test.go` (or a new `completion_test.go`):

# Ctrl+N starts a new session

## Problem

There is no keyboard shortcut to start a new conversation session within the REPL. Users must exit and re-launch `cake-repl` to begin a fresh session. This breaks flow during interactive use.

## Proposed solution

Add `Ctrl+N` as a key binding that ends the current session and immediately starts a new one. This should:

- Cancel any in-progress cake run (same as `Ctrl+C` during a run)
- Preserve the prompt history across the new session boundary
- Reset the timeline
- Keep the same model/profile settings
- Show a visual transition (e.g., a "New session" divider or status message)

## Considerations

- What happens to the current session summary? Should it be written out first?
- Should there be a confirmation if there's an unsaved session?
- Does `Ctrl+N` match conventions used by other Bubble Tea apps or terminal REPLs?

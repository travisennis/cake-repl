# Mouse/trackpad scrolling for timeline viewport

## Problem

The timeline viewport currently only scrolls via `PgUp`/`PgDn` keys. Users on laptops or with trackpads don't have dedicated page keys and expect mouse wheel / trackpad scrolling to work natively. The Bubble Tea `viewport.Model` already supports `tea.MouseMsg` for scroll events — we just aren't wiring them up.

## Relevant Files

- `cmd/cake-repl/main.go` — `tea.NewProgram()` call; needs `tea.WithMouseAllMotion()` to enable mouse event reporting.
- `internal/app/update.go` — `Update()` method; needs to handle `tea.MouseMsg` by forwarding to `m.timeline.Update(msg)`.
- `internal/app/commands.go` — `HelpText` constant; add mouse/trackpad scrolling mention.
- `internal/app/keys.go` — `keyMap` / `defaultKeyMap`; no new keys needed (mouse is not a key binding).
- `README.md` — Keybindings table; add mouse/trackpad scroll row.

## Fix Direction

1. In `main.go`, add `tea.WithMouseCellMotion()` to the `tea.NewProgram()` options (alongside `tea.WithAltScreen()`). This tells Bubble Tea to report mouse click, release, and wheel events.
2. In `update.go`, add a `case tea.MouseMsg:` in the `Update` switch to delegate to `m.timeline.Update(msg)`. The viewport model handles scrolling internally.
3. Update `HelpText` in `commands.go` and the keybindings table in `README.md` to document mouse scrolling.

Bubble Tea's `viewport.Model` already handles vertical scroll from mouse wheel events natively — no custom scroll logic needed.

# Tool output expansion — view full truncated output on demand

**Based on audit direction finding DIR-02** — audit commit `05f0916`

## Problem

Tool output is truncated at `DefaultOutputLimit` (2000 characters) with a marker `"\n… truncated (%d bytes total)"`. The full output is available in `FunctionCallOutput.Output` and stored in the item data, but there's no way to expand it in place.

The truncation is in `internal/ui/toolblock.go:103`:
```go
out := TruncateOutput(tool.Output, DefaultOutputLimit)
lines = append(lines, indent(th.ToolOutput.Width(width-2).Render(out), "  "))
```

## Decisions (grooming 2026-06-27)

1. **Selection model**: `Ctrl+O` to toggle the most recent tool block (matching acai's convention).
2. **Cycle toggle**: The toggle should cycle through three states: **no output** → **truncated** → **full** → (back to no output). This builds on tool output wrapping (task 033) which ensures tool names and arguments wrap properly.
3. **Rendering**: Expanding replaces the cached rendered item with full rendering; viewport position must remain stable.
4. **Output limit interaction**: Expansion shows full output regardless of `--output-limit`.

## Relevant files

- `internal/ui/toolblock.go` — `TruncateOutput`, `renderTool` call sites
- `internal/ui/timeline.go` — `ToolBlock` struct, `Item` rendering
- `internal/app/update.go` — `applyEvent`, `FunctionCallOutput` handling
- `internal/app/keys.go` — new key binding

## Constraints

- Must work with `--no-color`.
- Must not re-render the full timeline on toggle.
- The truncated/full state should be per-item, not global.
- Depends on tool output wrapping (task 033) being completed first.

## Implementation summary

- Added `ui.ToolOutputMode` with `Truncated` (zero/default), `Full`, and `Hidden` states.
- `ToolBlock` now carries `OutputMode`; new tool blocks default to `Truncated`.
- `renderTool` skips the output/status block when `Hidden`, ignores the output limit
  when `Full`, and keeps the existing truncation behavior when `Truncated`.
- `Ctrl+O` (`m.keys.ToggleToolOutput`) cycles the most recent `KindTool` item's mode
  and re-renders only that item via `rerenderItem`.
- `syncViewport` now restores the previous `YOffset` when not pinned to the bottom.
- Updated `HelpText`, `README.md`, and `docs/guardrails/cli-and-user-output.md`.
- Bumped `github.com/yuin/goldmark` from `v1.7.13` to `v1.7.17` to clear a pre-existing
  `govulncheck` finding (GO-2026-5320) and keep `just ci` green.

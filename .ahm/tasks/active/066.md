# Resolve the cake session-file path duplication in main

**Code-review finding (2026-07-28).** Involves a small user-visible decision;
left Open.

## Problem

`sessionFilePath` (`cmd/cake-repl/main.go:39-47`) hardcodes cake's on-disk
session layout:

```go
if d := os.Getenv("CAKE_DATA_DIR"); d != "" {
    return filepath.Join(d, "sessions", sessionID+".jsonl")
}
return filepath.Join(home, ".local", "share", "cake", "sessions", sessionID+".jsonl")
```

It is used only to print a hint after the TUI exits
(`cmd/cake-repl/main.go:235-243`).

This is the only place in the codebase that assumes anything about cake's
internal storage, and both `ARCHITECTURE.md` ("must never read or write cake's
session files") and
`docs/guardrails/cake-integration-and-stream-json.md` name that as outside the
contract. It encodes cake's data directory *and* its `CAKE_DATA_DIR` semantics
*and* its per-session filename scheme.

Nothing is broken today — the path is displayed, never opened. The cost is that
the hint silently becomes wrong the moment cake changes its data layout, and
there is no test or contract that would notice. It also lives in `cmd/` rather
than behind `internal/cake`, so the boundary violation is invisible to anyone
reading the engine package.

## Options

1. **Drop the path from the hint.** Print the resume command and the session
   id only. Smallest change, fully restores the boundary, loses a convenience.
2. **Move it into `internal/cake` as a declared part of the contract.** Keep
   the output, but put the assumption where the engine contract lives, name it
   explicitly in the guardrail as a documented dependency on cake's data
   layout, and accept that it must track cake releases.
3. **Ask cake for it.** Only viable if cake exposes the path through its CLI;
   out of scope unless that already exists.

Option 1 is the honest reading of the current architecture docs. Option 2 is
defensible but converts an accidental coupling into a maintained one, which
should be a conscious choice.

## Relevant Files

- `cmd/cake-repl/main.go` — `sessionFilePath`, `displayPath`, and the exit hint.
- `cmd/cake-repl/main_test.go` — has coverage for both helpers.
- `ARCHITECTURE.md`, `docs/guardrails/cake-integration-and-stream-json.md` —
  must agree with whatever is chosen.

## Acceptance criteria

- [ ] The chosen option is implemented and the exit hint's content is
      intentional.
- [ ] `ARCHITECTURE.md` and the cake-integration guardrail no longer contradict
      the code: either no session-file knowledge exists, or it is documented as
      a named exception with its maintenance cost stated.
- [ ] Tests updated to match.

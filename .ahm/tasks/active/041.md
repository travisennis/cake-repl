# Add CLAUDE.md symlink to AGENTS.md for agent discoverability

**Based on `docs` audit finding** — `agent_entry_point` scored 2/3 because while AGENTS.md is a strong entry point, there is no `CLAUDE.md` symlink to make it discoverable by tools that default to that filename.

## Problem

The project's agent entry point is `AGENTS.md` — a tool-agnostic file that works with acai, Copilot, Cursor, and other systems that recognize this convention. However, some tools (including Claude Code) default to looking for `CLAUDE.md` at the repo root. Without a symlink from `CLAUDE.md` → `AGENTS.md`, those tools may not find the entry point automatically, and the agent would fall back to guessing from README.md or source.

A symlink is the recommended pattern from the `docs` skill rubric: "a symlink from `CLAUDE.md` to `AGENTS.md` is ideal" for the `agent_entry_point` dimension at score 3.

## Relevant Files

### To create
- `CLAUDE.md` — symlink to `AGENTS.md` (committed to the repo).

### No changes needed
- `AGENTS.md` — unaffected; it remains the single source of truth.
- `.gitignore` — verify symlinks are not excluded.

## Fix Direction

```bash
cd /path/to/repo
ln -s AGENTS.md CLAUDE.md
git add CLAUDE.md
```

On macOS/Unix, `ln -s` creates a relative symlink. Verify it resolves:

```bash
readlink CLAUDE.md   # must output AGENTS.md, not an absolute path
```

### Commit

Add the symlink to the repo. No other files need changing.

### Acceptance criteria

- [ ] `CLAUDE.md` exists at the repo root as a symlink to `AGENTS.md`.
- [ ] `readlink CLAUDE.md` outputs `AGENTS.md` (relative, not absolute).
- [ ] `cat CLAUDE.md` shows the content of AGENTS.md.
- [ ] Git tracks the symlink (test with `git status`).
- [ ] The symlink works on macOS and Linux. On Windows with
      `core.symlinks=false`, Git may check it out as a regular file containing
      `AGENTS.md`; record that known limitation in the task handoff.

## Constraints

- The symlink must be relative (`AGENTS.md`), not absolute (`/Users/.../AGENTS.md`), so it works across checkouts.
- Do not rename or modify `AGENTS.md` — the symlink points to it; the content lives only in AGENTS.md.
- Windows users who clone without `core.symlinks=true` will see an empty file or a file-to-be-created. This is a known cross-platform limitation of Git symlinks and is acceptable for a project targeting primarily macOS/Linux development.

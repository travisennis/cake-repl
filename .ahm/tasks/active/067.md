# Decide whether -cwd should select the project-local config directory

**Code-review finding (2026-07-28).** Ambiguity in intended behavior; left Open.

## Problem

The implementation and ADR 002 intentionally resolve `.cake-repl.toml` relative to the process working directory, while `-cwd` changes only the directory passed to cake. The README says `current directory` but does not explicitly distinguish these two directories, so users can reasonably assume that `-cwd` also relocates project-local config. The code matches the accepted contract; the remaining defect is ambiguous documentation.

## Options

1. **Resolve project-local config against the resolved `-cwd`.** Makes "the
   project" one directory. Changes behavior for anyone using `-cwd` today.
2. **Keep current behavior, document it sharply.** State in the README and ADR
   002 that project-local config follows the shell's directory, not `-cwd`.
3. **Search both, with a defined precedence.** More surface, probably not worth
   it.

Option 1 is the least surprising, and `-cwd` usage is likely rare enough that
the behavior change is cheap — but it is a behavior change to a documented
contract, so it needs the decision recorded.

## Relevant Files

- `README.md` — clarify the `-cwd` flag and project-local config path.
- `docs/guardrails/cli-and-user-output.md` — record the same distinction in the compatibility surface.
- `docs/adr/002-config-file-for-repl-defaults.md` — accepted source of truth; verify rather than rewrite it.
- `internal/config/config.go` and `internal/config/config_test.go` — implementation and existing test proving that the local path remains the relative `.cake-repl.toml`.

## Acceptance criteria

- [ ] The README flag table and config-path section explicitly distinguish the process working directory from the `-cwd` cake execution directory.
- [ ] The CLI/output guardrail records the same behavior.
- [ ] ADR 002 remains unchanged and is cited as the existing decision.
- [ ] No code, config precedence, or path-resolution behavior changes.
- [ ] The existing `TestDefaultPaths` coverage for relative `.cake-repl.toml` remains valid.
- [ ] Rendered Markdown is inspected and `ahm status` reports valid indexes.

## Fix Direction

Preserve the existing behavior. State explicitly that project-local config is loaded from the shell/process working directory and that `-cwd` changes only cake's execution directory. Do not search both directories, change precedence, or alter config loading. Leave ADR 002 unchanged because this documents its existing decision rather than changing it.

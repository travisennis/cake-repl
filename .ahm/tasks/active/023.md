# Add /model and /profile slash commands

**Based on audit direction finding DIR-01** — audit commit `fe9b393`

## Problem

`--model` and `--profile` are startup-only CLI flags (`cmd/cake-repl/main.go:28-29`).
There is no way to switch model or profile mid-session without quitting and
restarting. Users experimenting with different models — a common workflow
with coding assistants — must exit and re-enter the REPL each time.

The session state machine already demonstrates how mid-session state changes
work: `/new`, `/continue`, `/resume` all modify what the next `cake.Start`
call uses. `/model` and `/profile` would follow the same pattern.

## Current status

Dependency 014 is completed. The task is not ready for implementation until
its required ADR records the command semantics and documentation impact.

## Next Action (grooming 2026-07-21)

Create the ADR before accepting this task. The ADR should choose `/model` and
`/profile` with no argument as read-only status commands and the literal
argument `default` as the way to clear an override; an empty quoted argument is
not part of the command grammar. It must also decide whether these commands are
rejected during an active run, consistent with task 051's session-command
policy. Link the accepted ADR here, replace the draft acceptance label below,
and then run `ahm task accept 023`.

## Investigation needed

1. **State location** — `Model` and `Profile` currently live on `Config`
   (immutable at startup). They need to move to mutable state on the Model
   or `sessionState` so `startRun` can read the current value. `Config`
   keeps the initial values as defaults.

2. **Command shape** —
   - `/model` with no arg: show current model.
   - `/model <name>`: set the model for the next prompt.
   - `/model default`: clear the model override (use cake's default).
   - Same for `/profile`.

3. **Status line** — `view.go:statusLine()` already shows `model <name>`
   when set. It should reflect the current value after a `/model` command.

4. **HelpText and README** — add `/model` and `/profile` to the slash
   commands table in `HelpText` (`commands.go`), `README.md`, and
   `AGENTS.md` routing.

5. **ADR required** — this is a `type:feature` task that changes user-visible
   behavior and the command surface. Create an ADR before implementation
   per `docs/adr/README.md`.

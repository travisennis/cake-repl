# Investigate inline terminal rendering without alternate screen

## Summary

Evaluate a Codex-like startup and rendering mode that preserves visible terminal history above cake-repl while retaining a usable live timeline, composer, status line, resizing, and scrolling.

## Context

`cmd/cake-repl/main.go` currently starts Bubble Tea with
`tea.WithAltScreen()`, which switches to a full-window alternate buffer and
restores the original terminal contents on exit. Removing that option would
preserve terminal scrollback, but `internal/app/model.go` currently sizes the
timeline from the full terminal height. A one-line change may therefore push
the recent shell history out of the visible window rather than provide the
Codex-like inline experience being requested.

Investigate and compare at least:

- normal-buffer rendering with only `tea.WithAltScreen()` removed;
- a bounded or content-aware inline viewport that leaves recent terminal
  history visible above the active REPL;
- committing completed transcript output to terminal scrollback while keeping
  only the active composer/status region live, using Bubble Tea facilities or
  another appropriately small design.

Account for startup and exit behavior, terminal resize, long conversations,
live streaming output, keyboard and mouse scrolling, `/clear`, `-no-color`,
and the post-exit resume message. Determine whether inline rendering should
replace the current default or be exposed as an explicit mode, and identify
any CLI, documentation, testing, or architectural compatibility impact.

This is an investigation task. Production implementation is out of scope;
small disposable prototypes are acceptable when needed to establish terminal
behavior.

## Acceptance Notes

- [ ] Record terminal experiments for each viable approach, including behavior

- [ ] Recommend an approach and explain its UX, implementation complexity,

- [ ] Define the likely implementation scope, affected compatibility surfaces,

- [ ] Create any follow-up implementation task or ADR that the recommendation
